# Cozy Cubs Australia 2026 Website

# cozycubs-2026

Official Next.js 16 website for **Cozy Cubs Australia** — Australia's #1 custom bedding studio. Featuring interactive 3D bed customizer, GOTS organic cotton specifications, Square payment gateway integration, and enterprise-grade SEO architecture.

## Tech Stack
- **Framework:** Next.js 16 App Router (Turbopack)
- **Styling:** Custom CSS with Glassmorphism UI tokens
- **Icons:** Lucide React
- **Payments:** Square Web Payments API
- **SEO Architecture:** Dynamic XML Sitemap, Robots Directives, Web Manifest, Schema.org JSON-LD (OnlineStore, Product, Offer, FAQPage, ItemList, Breadcrumbs, Article).

## Getting Started
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
